# Rift в браузере

P2P-мессенджер. Ядро написано на Rust и собрано в WebAssembly, поэтому
браузер говорит ровно по тому же протоколу, что и настольное приложение:
те же MLS-сессии, та же история, тот же формат кадров.

Никакого своего сервера: статика лежит на GitHub Pages, а соединения
идут напрямую между узлами.

## Профили

Личность лежит в хранилище браузера, а оно общее для всех вкладок сайта.
Поэтому вкладка без параметров - это вы, а вкладка с `?profile=2` - второй
человек со своим ключом и ником.

## Подключение к настольному узлу

Настольное приложение раздаёт этот же клиент у себя и принимает
WebSocket-подключения браузера. Адрес моста - в корне, клиент - в /app/:

    http://<адрес-узла>:8090/app/
